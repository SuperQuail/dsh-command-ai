# dsh-command-ai

为 DSH 添加 CommandCode 提供商，支持模型目录拉取、手动添加模型，以及逐模型设置图片输入、思考档位和容量。

## 配置

1. 打开 **设置 → 模型 → 添加提供商 → CommandCode**。
2. 在 **CommandCode 配置** 中填写 API Key。
3. 点击 **保存 CommandCode**，然后在聊天中选择模型。

默认 API 地址为 `https://api.commandcode.ai/provider/v1`。也可通过 `CMD_API_KEY` 环境变量提供密钥；留空保存会保留已有密钥。

请使用插件配置区的 **保存 CommandCode**，而不是上方通用编辑器的保存按钮。

## 模型能力

在 **自定义设置 → 模型能力配置** 中展开模型：

- 已知支持图片的模型默认勾选图片，并启用对应的思考档位。
- 可手动调整文本/图片输入、思考档位及上游值。
- 上下文和输出容量支持 `256K`、`1M` 等写法（1K = 1000）；输出留空使用默认预算（32K，即 32768）。
- 手动设置优先；点击 **恢复继承的能力** 可恢复默认值。

取消所有思考档位只会隐藏可选档位，并不代表关闭上游思考。默认能力来自官方 CLI 声明；若实际接口不支持，可手动调整。

## 拉取或添加新模型

进入 **自定义设置 → 添加模型**：

1. 点击 **拉取模型目录**，从结果选择新模型；也可直接输入模型 ID。
2. 确认 API 协议和上下文容量，输出容量可留空。
3. 点击 **添加模型**，按需调整图片支持和思考档位。
4. 点击 **保存 CommandCode** 后生效。

拉取失败不影响手动添加。拉取和保存不会发送收费聊天请求，也不会覆盖已有模型设置。移除自定义模型后同样需要保存。

## 常见问题

- **接口报错 `unknown field "summary"`**：保持“省略 reasoning.summary”开启，或使用 Chat Completions。
- **新模型仍不可用**：确认模型 ID、协议与账号权限；添加到列表不代表上游已开放访问。
- **修改 API 地址后拉取失败**：旧密钥不会自动发送到尚未保存的新地址，请确认地址与对应密钥。
